# GP_ORBIT

Experimental portfolio, creative lab, and web playground.

## Live Projects

### Orbit

Primary portfolio experience and navigation system.

### Sine Lab

Interactive audio and melody experimentation.

### Gradient Lab

Typography, gradients, shaders, and visual experiments.

### Odds

Sports data visualization prototype.

## Tech Stack

- HTML
- CSS
- JavaScript
- Python
- Three.js
- Vercel

## Development Workflow

1. Create a feature branch
2. Make changes
3. Commit locally
4. Push to GitHub
5. Open Pull Request
6. Merge into `main`
7. Deploy via Vercel
